# Générateur de documents fictifs

Variables : noms fictifs, âge, rôle adhérent/conjoint/enfant, composition familiale, type de soin, dates, montants, BRSS, AMO, formule d exercice, pièces présentes, anomalies, difficulté.

Cas : normal, pièce manquante, doublon, mauvais bénéficiaire, droits fermés, facture non acquittée, ordonnance absente, incohérence devis/facture, plafond atteint, acte non garanti, document illisible, RIB invalide, date incohérente.

Sortie : case.json + PDFs + answer_key.json + metadata.json. Seed obligatoire pour reproductibilité.

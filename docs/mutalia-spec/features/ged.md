# GED pédagogique

Documents : décompte AMO, facture acquittée, ordonnance, devis/facture dentaire, devis/facture optique, prescription, PEC hospitalière, attestation de droits fictive, RIB fictif invalide, réclamation, audiologie.

Workflow : Importé -> À qualifier -> Associé -> Contrôlé -> Conforme / Incomplet / Anomalie -> Traité -> Archivé.

L apprenant classe, associe, contrôle, relève les données, détecte les anomalies, demande des pièces, calcule et justifie. PDF/JPG/PNG acceptés. Corrigé caché en mode apprenant.
